# CTI-Dashboard-Concept


This repository hosts a concept visualization of a Cyber Threat Intelligence (CTI) dashboard designed to transform enriched vulnerability data into actionable insights. The goal is to demonstrate how threat‑intelligence signals (EPSS, KEV, exploit data, ATT&CK mapping, exposure context, and vendor impact) can be unified into a single decision‑ready view.

## Overview

This project explores how enriched CVE data can be visualized using a modern dashboard layout. The concept image included in this repository highlights how threat‑intelligence metrics can support faster, more informed remediation decisions.

The dashboard showcases:
- Remediation priority heatmap
- EPSS vs exploitability analytics
- KEV coverage indicators
- Public exploit visibility
- Exposure breakdown (internet‑facing, internal, unknown)
- MITRE ATT&CK technique clustering
- Top affected vendors
- Detailed CVE scoring and metadata

This is a conceptual design, not a production dashboard.
